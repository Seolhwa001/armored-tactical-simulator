# ATS Game Design Document

문서 버전: 0.1  
프로젝트: Armored Tactical Simulator  
상태: 초안

## 1. 프로젝트 개요

ATS는 모바일 환경에서 전차장과 소대장의 판단을 체험하는 턴제 전술 시뮬레이션 프로젝트다.

## 2. 핵심 플레이 모드

### 2.1 단차전투기술

플레이어는 전차장의 입장에서 단차 전투 상황을 판단하고 조치한다.

### 2.2 소대전투기술

플레이어는 소대장의 입장에서 휘하 전차를 지휘하고 소대 전투 상황을 판단한다.

## 3. 핵심 설계 원칙

- 실제 전장 상태와 플레이어가 아는 정보를 분리한다.
- 아군과 적군은 동일한 기본 탐지 규칙을 사용한다.
- 지형은 이동, 시야, 은폐 및 엄폐에 영향을 준다.
- 명령과 위협에는 시간의 흐름이 존재한다.
- 모바일에서 확인하고 조작하기 쉬운 인터페이스를 우선한다.

## 4. 개발 범위

### 우선 구현

- 모바일 전투 화면
- 육각형 지도
- 지형
- 이동
- 전장의 안개
- 감시 및 정찰
- 단차전투기술
- 소대전투기술
- 개발자 메뉴

### 이후 구현

- 훈련
- 인사 및 성장
- 생활기록부
- 대대급 지휘
- 장군으로의 길
