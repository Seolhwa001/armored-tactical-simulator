Armored Tactical Simulator


Armored Tactical Simulator, ATS는 모바일 환경에서 기갑 단차 및 소대 단위의 전투 상황을 가시화하는 턴제 전술 시뮬레이션 프로젝트입니다.

 
이 프로젝트의 핵심은 무기 성능 자체를 정밀하게 재현하는 것이 아니라, 제한된 정보와 지형, 지휘, 관측, 통신, 기동 판단이 전투 결과에 어떤 영향을 주는지 표현하는 것입니다.




전장은 복잡하되, 인터페이스는 명확해야 한다.

실제 전장 상태와 플레이어가 알고 있는 정보는 분리되어야 한다.

2. 핵심 설계 원칙


불완전한 정보


플레이어는 게임 내부의 실제 적 위치를 직접 알 수 없습니다.


적 정보는 다음 과정을 거쳐 표시됩니다.


미확인 접촉
→ 인원 또는 차량 추정
→ 객체 성질 추정
→ 규모 추정
→ 개별 객체 확인



과거에 확인한 적은 실제 위치를 따라가지 않으며, 마지막 관측 위치와 정보 신뢰도만 남습니다.


대칭적인 탐지 규칙


아군과 적군은 동일한 기본 탐지 규칙을 사용합니다.


한쪽이 먼저 탐지했다면 다음과 같은 설명 가능한 이유가 있어야 합니다.




감시 방향


지형


은폐 상태


이동 속도


관측장비 상태


표적 노출


정보 공유 여부




적에게 근거 없는 전용 시야 보너스를 주지 않습니다.


지속 명령


이동 명령의 최종 목적지는 다음 상황이 발생할 때까지 유지됩니다.




목적지 도달


이동 명령 취소


새로운 이동 목적지 지정


기동 불능


기존 이동을 대체하는 명령 하달




감시나 사격명령을 내렸다는 이유만으로 기존 최종 목적지가 사라지지 않습니다.


지형은 전투 규칙


지형은 배경 장식이 아니라 다음 요소를 결정합니다.




이동 가능 여부


이동 비용

관측 보정

진지 활용 가능 여부


예상 은거지역 생성




모바일 우선


전투 화면은 다음의 3단 구조를 기본으로 합니다.


상단 상태바
────────────
육각형 전술 지도
────────────
커맨드 패널
턴 실행 버튼



지도와 커맨드는 서로 겹치지 않아야 하며, 주요 버튼은 한 손 조작이 가능한 크기를 유지합니다.



3. 전투 진행 방식


ATS는 WEGO 방식의 턴제를 사용합니다.


상황 확인
→ 행동 선택
→ 명령 예약
→ 턴 실행
→ 아군과 적군 동시 행동
→ 관측 및 피해 결과 갱신
→ 다음 판단



모든 행동은 즉시 결과가 발생하는 버튼식 판정이 아니라, 이동·관측·사격·위협 접근이 시간의 흐름을 가지도록 구성합니다.

5. 승무원 및 화기 체계


전차 승무원은 각자 역할과 작업 상태를 가집니다.




전차장


포수


탄약수


조종수




주포 운용


가상의 승무원 사격 절차를 사용합니다.


전차장
승무원 → 탄종 → 방향 → 거리 → 표적 성질·규모

탄약수
장전 끝

포수
표적 확인 → 조준 끝

전차장
쏴 또는 쏴-수정



발사 통제




쏴: 정확히 한 번만 발사


쏴-수정: 첫 발 이후 포수가 같은 표적에 대한 후속 교전을 지속


사격 그만: 조준, 후속 사격, 차기 장전을 중지




탄종


게임에서는 다음 탄종을 사용합니다.




날탄


대탄


벌집탄


연막탄




모든 성능 수치는 실제 무기 제원이 아닌 게임 내부의 상대적 효과값으로 관리합니다.


승무원별 기관총




전차장: 전차장기관총


포수: 공축기관총


탄약수: 탄약수기관총




기관총은 승무원 작업 상태에 따라 동시 운용할 수 있습니다.


주포 운용 중에는 포수가 주포를 담당하고 탄약수가 장전을 담당하므로, 해당 승무원의 다른 화기 운용은 제한됩니다.

13. 개발 원칙




새로운 아이디어는 먼저 문서화한 뒤 구현한다.


실제 전장 상태와 플레이어 인지 상태를 분리한다.


적 AI도 전장의 안개와 불완전한 정보를 적용받는다.


모든 불리한 결과에는 플레이어가 이해할 수 있는 원인이 있어야 한다.


모바일에서 보이지 않거나 누르기 어려운 기능은 구현 완료로 보지 않는다.


수정할 때마다 기존 핵심 기능의 회귀 테스트를 수행한다.


실제 무기 운용 제원보다 게임 내 판단과 인과관계 표현을 우선한다.
